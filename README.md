# Vapenboken – färdiga filer

Det här repot innehåller **bara de byggda programfilerna** för
Vapenboken, samt det signerade manifest som programmets
uppdateringskontroll läser. Källkoden ligger någon annanstans och är
inte publik.

Hämta programmet under [**Releases**](../../releases/latest) – ladda
ner **en** fil:

| Dator | Fil |
|---|---|
| Windows | `Vapenboken.exe` |
| Mac med Apple M1 eller senare | `Vapenboken-mac-apple-silicon.zip` |
| Mac med Intel-processor | `Vapenboken-mac-intel.zip` |

Vilken Mac du har står under *Apple-menyn → Om den här datorn*. Står
det **Chip: Apple M…** är det Apple Silicon, står det **Processor:
Intel…** är det Intel. Fel fil startar inte alls.

Installationsanvisningar står på varje releasesida.

Filerna läggs upp automatiskt av byggkedjan. Lägg inget här för hand.
